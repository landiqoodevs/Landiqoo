# 3. VISUAL DESIGN DIRECTION

Use a Hybrid Premium design system.

Combine elegant white sections with carefully selected dark sections, sophisticated typography, subtle gradients, and modern website previews.

The website should feel premium, distinctive, creative, and professionally art-directed.

## Color Palette

Use the following colors as the initial design system:
- Deep Navy: #0B1020
- Electric Blue: #4F7CFF
- Violet Accent: #8B5CF6
- White: #FFFFFF
- Light Background: #F7F8FC
- Primary Text: #111827
- Secondary Text: #6B7280
- Border Color: #E5E7EB

Use these colors consistently. Do not apply every accent color everywhere.

## Typography

Use modern, premium typography with a clear hierarchy.

Choose a suitable contemporary font combination, such as:
- Inter
- Manrope
- Plus Jakarta Sans

Select a font pairing that suits the overall design. Avoid using too many different fonts.

## Design Characteristics

- Bold, memorable headlines.
- Excellent whitespace and spacing.
- Clear visual hierarchy.
- Elegant light and dark section transitions.
- Restrained blue-to-violet gradients.
- Sophisticated website mockups.
- Subtle shadows and borders.
- Polished buttons and hover effects.
- Smooth scrolling and restrained animations.
- Modern layouts with deliberate composition.
- Consistent alignment and spacing.
- Carefully designed mobile experiences.

Avoid:
- Generic AI-generated website layouts.
- Excessive gradients and glowing effects.
- Overuse of rounded cards.
- Unnecessary animations.
- Excessive icons and decorative elements.
- Crowded sections.
- Huge blocks of text.
- Repetitive portfolio cards.
- Fake statistics and unsupported marketing claims.

The result should look like a premium design studio's real website, not a basic template.

Preferred technologies:

- Vite

If the existing project uses a different setup, inspect it before making changes and explain whether it makes sense to retain or adjust it.

Do not replace or overwrite existing project files without inspecting them first.

## Code Quality

- Use reusable React components.
- Keep components logically organized.
- Use clean, understandable naming conventions.
- Separate repeated UI elements into reusable components.
- Avoid unnecessary dependencies.
- Keep the code easy for a beginner to understand.
- Use semantic HTML.
- Implement responsive layouts.
- Ensure accessible contrast and keyboard navigation.
- Include appropriate alt text for meaningful images.
- Use optimized images.
- Avoid layout shifts where practical.
- Add meaningful hover and focus states.
- Check that all buttons and links behave as expected.
- Keep the browser console free from avoidable errors.
- Ensure the application builds successfully.

I am learning web development. I want to understand how the website is built, not simply receive a massive block of code.

Follow these rules:

2. Inspect the project folder before making changes.
3. Explain what already exists and what needs to be configured.
4. Present a short plan before beginning major implementation.
5. Tell me what each important terminal command does.
6. Explain the purpose of important files and components.
7. Build the website in manageable stages.
8. Explain important design and coding decisions.
9. Help me diagnose errors rather than hiding them.
10. Tell me how to start the development server.
11. Explain how to preview and test the website.
12. Ask before making major architectural changes.
13. Avoid unnecessarily complicated code.
